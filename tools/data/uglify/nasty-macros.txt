# tools/uglify.py renamed them (DECISIONS §2): neither keywords, nor reserved ([lex.name]/4), nor
# declared by the standard library ([macro.names]/1), so a program may #define any of them.
# tests/ycxx/support/nasty_macros.hpp defines each (tools/uglify.py --gen-tests); the
# conformance/nasty_macros* tests include every public header after it. tools/uglify.py --check
# keeps new ones from appearing.
#
# tools/uglify.py adds the names it renames in include/ to this list (sorted, wrapped), so a merge
# that brings new plain names gets them tested too.
#
# [not-definable]: left out, the names that break glibc's headers, which the public headers
# include (with _GNU_SOURCE, which g++ and clang++ define), when they are macros: glibc declares
# or uses them itself, so that no program can define them whatever libycxx does (found by
# defining each).
